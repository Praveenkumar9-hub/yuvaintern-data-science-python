# YuvaIntern Task 1 – Data Acquisition, Cleaning and Preprocessing

## Internship
Virtual Data Science with Python Trainee

## Objective
The objective of this task is to acquire a publicly available dataset,
analyze its quality, identify missing values and inconsistencies,
perform data cleaning and preprocessing using Python, and document
the complete process.

## Dataset
UCI Adult / Census Income Dataset

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Work Performed
- Dataset acquisition
- Initial data exploration
- Missing-value identification
- Missing-value handling
- Text normalization
- Duplicate checking
- Range and consistency checks
- IQR-based outlier analysis
- Final validation
- Cleaned dataset generation

## Files
- `task1_analysis.py` – Python analysis and preprocessing code
- `adult_cleaned_task1.csv` – Cleaned dataset
- `adult_outlier_report_task1.csv` – Outlier analysis report

## Dataset Source
UCI Machine Learning Repository – Adult Dataset
