# YuvaIntern Task 2 – Exploratory Data Analysis and Visualization

## Internship
Virtual Data Science with Python Trainee

## Objective
Perform exploratory data analysis and visualization on a public dataset using Python.

## Dataset
Palmer Penguins Dataset

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Initial dataset inspection
- Descriptive statistics
- Missing-value analysis
- Species distribution analysis
- Body mass distribution
- Flipper length vs body mass analysis
- Bill length vs bill depth analysis
- Correlation analysis
- Species-level aggregation
- Outlier analysis

## Key Findings
The analysis explores differences between penguin species and relationships
between their physical measurements. Particular attention is given to the
relationship between flipper length and body mass and differences in body
measurements between species.
