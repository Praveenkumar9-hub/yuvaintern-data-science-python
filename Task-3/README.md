# YuvaIntern Task 3 – Unsupervised Learning and Clustering Analysis

## Internship
Virtual Data Science with Python Trainee

## Objective
Apply unsupervised learning techniques to a publicly available dataset using Python and Scikit-learn.

## Dataset
Iris Dataset

## Algorithm
K-Means Clustering

## Techniques Used
- Data preprocessing
- Feature standardization
- K-Means clustering
- Elbow method
- Silhouette score
- Principal Component Analysis (PCA)
- Cluster profiling
- Data visualization

## Tools & Libraries
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Task Overview
This project analyzes the Iris dataset using K-Means clustering to discover meaningful groups based on flower measurements without using the original species labels during model training.

## Files
- `task3_clustering_analysis.py` – Python implementation
- `task3_iris_clustered.csv` – Clustered dataset
- `task3_k_selection_metrics.csv` – K selection results
- `task3_cluster_profiles.csv` – Cluster profiles
- `visualizations/` – Generated charts
