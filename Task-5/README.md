# YuvaIntern Task 5 – Deep Learning Application in Data Science

## Project
Handwritten Digit Recognition using a Neural Network

## Objective
Apply neural-network concepts to classify handwritten digit images.

## Dataset
Public handwritten Digits dataset

## Model
Multilayer Perceptron Neural Network

## Architecture
Input (64) → Dense 128 → Dense 64 → Output (10)

## Techniques Used
- Data normalization
- Neural network training
- ReLU activation
- Adam optimizer
- Early stopping
- Confusion matrix
- Accuracy, Precision, Recall and F1-score
- Training and validation analysis

## Tools
- Python
- Pandas
- Scikit-learn
- Matplotlib
