# YuvaIntern Task 6 – Integrative Capstone Project

## Project
Student Performance Prediction and Segmentation

## Objective
Build an end-to-end Data Science pipeline using a public student-performance dataset.

## Pipeline
Data Collection → Cleaning → EDA → Feature Engineering → Supervised Learning → Unsupervised Learning → Evaluation → Insights

## Dataset
UCI Student Performance Dataset – Portuguese course

## Supervised Learning
- Random Forest Classifier
- Pass/Fail prediction
- 5-fold cross-validation
- Accuracy, Precision, Recall and F1-score
- Confusion Matrix

## Unsupervised Learning
- K-Means Clustering
- Silhouette Score
- PCA visualization
- Cluster profiling

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
